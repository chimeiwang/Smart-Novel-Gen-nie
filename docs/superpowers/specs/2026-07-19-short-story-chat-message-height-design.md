# 中短篇对话消息自然高度设计

## 问题

消息记录区使用可伸展的 Grid 容器。Grid 默认的纵向内容对齐会拉伸隐式消息轨道，因此只有一条消息时，消息卡片占满整个记录区，作者和正文之间出现大块空白，正文看起来被垂直居中。

## 设计

保留现有 Grid、滚动、消息间距和左右缩进，只在消息记录容器上设置 `align-content: start`。消息轨道按内容自然高度从顶部排列，剩余高度留在消息列表底部。消息卡片本身不设置固定高度或最大高度，长回复仍可自然增长并由记录区滚动。

不改为 Flex，不改消息颜色、圆角、输入区或三栏结构，避免扩大本次视觉修复范围。

## 验收

- 单条短消息卡片高度只包裹标题与正文。
- 多条消息从顶部依次排列，间距保持不变。
- 长消息仍可完整显示并通过消息记录区滚动。
- 底部输入区位置与高度保持不变。

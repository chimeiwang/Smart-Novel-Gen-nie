## 一、污染与矛盾清理

### 玄天宗与玉虚子

1. 玄天宗势力说明中的掌门“玉衡子”统一改为“玉虚子”。
2. 玉虚子的 `powerLevel` 设为“化神期”。
3. 玄天宗成员说明使用以下权威表述：

> 掌门“玉虚子”：化神期修士，修为受灵力衰退影响而跌落。修炼《玄天正气诀》，擅长以磅礴灵压和阵法驾驭大势，是宗门稳健强硬派的核心人物，也是飞升计划的主要知情者之一。

4. “在飞升事件后，有意的增了许多不同修行法门的弟子”改为“在飞升事件后，有意增加了许多修行
   不同法门的弟子”。
5. 其他“玉虚子等掌门长老”的现有表述保留。

### 言不言

1. `personality` 中“而且为人很逗，总喜欢逗大家开心”替换为：

> 偶尔会用眼神、动作和极短的回答制造冷幽默，但不会为逗趣而说无意义的话。

2. `specialSkills` 只保留以下内容：

> 千金一剑：将长期沉默积攒的“言灵”之力与剑气融合，出剑时可伴一句真言。此剑不仅物理威力巨大，真言更能直接冲击对手神魂，动摇其意志与对自身道法的信念。
>
> 一字真言：在非战斗状态下，可将高度浓缩的“言灵”之力融入单个字词中，产生类似言灵术的效果。每次使用都消耗巨大，非紧要关头不用。
>
> 心语剑鸣：以剑气轻微震荡空气，模拟简短、无感情色彩的语调，用于传递“可”“否”“方位”等最基本的信息。

3. 从 `specialSkills` 移出的状态说明写入 `statusNote`：

> 作为经历过灵气大年与灵力衰退的黄金一代成员，他支持玉虚子的平稳过渡方针，但比玉虚子更悲观，认为真话的成本太高，世人未必负担得起。

### 孙福来

1. 身世以现有主 `background` 为权威：农家出身，三岁时遭遇山洪，被云中子从树上救下并带回玄天宗。
2. 删除误粘在 `specialSkills` 中的“铁匠之子、山体滑坡、被埋三天三夜”版本，不保留或合并该版本。
3. `specialSkills` 只保留以下内容：

> 被动挨打：长期遭遇意外使他积累了异常丰富的危险反应经验，闪避和应急能力远高于同境界普通修士。
>
> 异常运气：好运和坏运都可能以出人意料的方式出现，没有规律、来源或补偿关系；孙福来本人无法预测、控制或利用运气。

4. 从 `specialSkills` 移出的当前近况写入 `statusNote`：

> 正在努力修炼，试图摆脱“宗门最大负资产”的称号。

孙福来的运气不进入作品圣经。

### 飞升计划统一口径

故事背景和世界设定统一使用以下因果链：

1. 灵气大年结束后灵力先出现异常下降。
2. 飞升计划的实际目标是解决灵力衰退：人为建立新的高浓度灵力输入通道。
3. 计划的技术方案是先让一名顶尖修士穿过裂缝，在另一侧确认环境并建立锚点，再把裂缝稳定为输入通道。
4. 参与者误判了裂缝对面的环境；另一侧不是高灵力世界，而是虚空。
5. 锚定失败后裂缝成为永久输出通道，使原本缓慢的衰退骤然加速。
6. 对外继续宣称本轮衰退是自然周期和灵气大年透支的结果；真正目标、技术方案和事故原因仅限少数知情者掌握。

故事背景中“为世界补充灵力”和世界设定中“让一名修士穿越实现飞升”不再作为两个独立计划描述，
而分别作为同一计划的目标与技术步骤。

## 三、作品圣经最终内容

### genre

> 末法修仙、遗产冒险、悬疑解谜、群像成长

### targetReaders

> 喜欢理性世界观、遗迹探索、长期谜团、制度冲突和克制成长线的长篇读者。

### coreSellingPoint

> 灵力消亡使旧修仙文明留下的洞天、封印和法器逐步崩溃；主角以遗产猎人身份处理灾难，在一次次任务中拼出师门共同隐瞒的飞升真相。

### readerPromise

> 每个主要阶段解决一个具体遗产危机，揭示一块可验证的真相碎片，并推动人物关系发生不可逆变化；力量成长始终服从灵力衰退规则，不靠突然恢复灵气解决问题。

### appealModel

> 遗产任务钩子 → 现场规则破解 → 战斗与选择 → 获得资源或线索 → 飞升真相推进 → 师徒及阵营关系变化 → 引出更高风险遗产。

### taboo

> 不引入系统或无代价金手指；不让灵力突然复苏，不用无限战力膨胀破坏末法前提；不靠人物突然降智维持谜团；不用偶然事件直接解决核心冲突；不反复使用“封印松动—打怪解决”的同质情节，每个遗产应有不同规则、利益关系和社会后果；纪寻的体术优势只能降低灵力依赖，不能让他无视境界、资源和行动代价。

作品圣经不写入针对玉虚子、孙福来或其他非主角人物的专属限制。

### comparableTitles

> 《诡秘之主》：只参考长期谜团、阶段揭示和组织博弈结构；《大道朝天》：只参考克制叙事、旧时代余韵和修行者立场冲突。不模仿具体人物、情节或语言风格。

### notes

> 故事开始时间固定为聚元历 4726 年。飞升事故发生于 4680 年，青石镇事故发生于 4705 年。当前灵力浓度约为峰值时期的 35%，并继续不可逆下降。遗产是依赖灵力维持、正在失控的旧时代超凡造物，不等同于普通遗迹。主线核心不是“谁偷走了灵力”，而是“人们是否有权用谎言维持秩序，以及真相公开后谁承担代价”。纪寻的体术优势只能降低对灵力的依赖，不能让他无视境界和资源约束。

`storyLengthProfile=long_serial` 与 `targetTotalWordCount=1_000_000` 保持不变。

## 验收标准

1. 玄天宗和人物设定中不再出现掌门“玉衡子”。
2. 言不言和孙福来的 `specialSkills` 不包含“当前状态”“状态备注”“背景”等误粘字段。
3. 孙福来只保留山洪获救版本，生产设定中不再出现铁匠之子、山体滑坡和被埋三天版本。
4. 故事背景与世界设定把补充灵力、修士穿越和裂缝锚定描述为同一飞升计划。
5. 故事开始年份、纪寻年龄、青石镇事故、拜师年份和飞升事故能够按时间线互相计算。
6. 作品圣经八个内容字段全部非空，且不包含针对非主角人物的专属限制。
7. 大纲正文、大纲节点、剧情进度、章节和本规格排除的其他设定保持不变。
8. 写入后通过生产公共 CLI 完整回拉 `long.planning.get`、`long.lore.get` 与 `long.novel.get`，逐项核对上述内容。

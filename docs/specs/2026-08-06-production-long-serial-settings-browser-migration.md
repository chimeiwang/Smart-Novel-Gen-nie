## 背景

源作品创建于篇幅 Profile 引入之前，没有 `WritingBible` 记录。Web 会把缺失 Profile 显示为长篇，
但生产长篇 CLI 的精确过滤只返回显式保存为 `long_serial` 的作品。用户希望新建一个长篇项目，复制
除大纲及剧情推进以外的全部创作设定，同时避免为低频迁移需求增加永久克隆接口或后台功能。

本次操作获得用户明确授权，可以使用已经登录的生产 Web UI。生产 CLI 继续只承担完整读取和权威
回拉验证；所有写入均通过现有 Web UI 和公共 `/api/v1/**` 业务接口完成，不使用 SSH、数据库、
Agent Service 或 `/internal/v1/**`。

## 目标

1. 新建显式 `long_serial` 目标项目《遗产猎人（迁移）》。
2. 完整复制源作品的设定与参考资料，并重建目标项目内的实体引用。
3. 不复制大纲、剧情推进、正文、章节状态及任何任务、审核、会话或计费历史。
4. 保留源作品及其全部数据，不执行删除、清空或覆盖。
5. 迁移后通过生产 CLI 回拉源、目标数据并逐类核对。

## 复制范围

### 项目与单例设定

- 复制 `Novel.summary`。
- 新建 `WritingBible`，固定 `storyLengthProfile=long_serial`；源作品没有作品圣经，因此目标总字数使用
  长篇默认值 `1_000_000`，其他缺失字段保持为空。
- 复制 `StoryBackground`。
- 复制 `WorldSetting`。
- 同一用户下复用源作品当前应用的 `WritingStyle`；不复制用户级文风实体、画像任务或文风参考文件。

### 世界观实体与关系

- `Location`，包括父地点关系。
- `Faction`，包括总部地点关系。
- `Character`，包括所属势力关系。
- `CharacterRelation`，包括关系方向和双方人物引用。
- `CharacterExperience` 中 `chapterId` 为空的前史/设定经历。
- `Item`，包括持有者关系。
- `Glossary`。

所有目标实体使用新 ID。迁移按依赖顺序建立源 ID 到目标 ID 的映射，禁止把源项目实体 ID 写入目标
项目。

### 参考资料

- 复制每条 `ReferenceMaterial` 的标题、类型、正文和来源链接。
- 不复制 `RagDocument` 或 `RagChunk`；目标项目通过现有参考资料创建流程重新建立索引。

## 明确排除

- `Outline` 文本总纲和全部 `OutlineNode`。
- `PlotProgress`、`Novel.storyProgress` 和 `Foreshadowing`。
- 源 `Chapter`、章节正文、章节目标、Beat Plan、Scene Beat、章节进度和质量检查。
- 绑定源章节的 `CharacterExperience`、`CharacterStateChange`。
- `ReviewArtifact` 及其 revision/evaluation。
- `WritingSession`、消息、任务、命令、事件、WorkflowRun 和 WorkflowStep。
- TokenUsage、CreditLedger 及其他计费、用量和运行历史。
- RAG 索引、向量和其他可重新生成的派生数据。

## 执行流程

1. 通过生产 wrapper 执行 `auth.whoami`，确认用户为 `nie`。
2. 通过 `long.novel.get`、`long.planning.get`、`long.lore.get`、`long.resources.get` 完整读取源作品；长内容
   写入本地临时输出文件，不截断。
3. 生成逐类迁移清单，记录源实体数量、名称和引用关系。
4. 在生产 Web UI 新建《遗产猎人（迁移）》，选择长篇连载和目标字数 `1_000_000`。
5. 依次保存故事背景、世界设定和作品圣经。
6. 按“地点 -> 势力 -> 人物 -> 人物关系/无章节经历 -> 物品 -> 术语”的顺序逐项创建并重建引用。
7. 逐条创建参考资料，等待其索引进入成功状态；明确记录失败项，不用旧索引冒充成功。
8. 重新应用源作品当前文风。
9. 通过生产 CLI 按目标 novelId 回拉目标详情、规划、设定和资源，执行最终核对。

## 中断与恢复

- 源作品始终只读，任何失败都不得修改或删除源数据。
- 每完成一个实体即在本地清单记录源 ID、目标 ID 和结果；浏览器或网络中断后从清单继续，不重复创建。
- 遇到字段保存失败、引用无法解析或权限异常时立即停止，不用空值静默替代。
- 若目标项目出现无法安全恢复的部分状态，保留目标并报告，不自动删除；删除需要用户另行明确授权。

## 验收标准

1. `long.novel.get` 返回目标作品为显式 `long_serial`，且 `long.novel.list` 能列出目标作品。
2. 源、目标的故事背景和世界设定正文完全一致。
3. 人物、势力、地点、物品、术语、人物关系和无章节人物经历的数量及业务字段一致；忽略 ID 和时间戳。
4. 目标项目内所有实体引用均指向目标项目的新 ID，不残留源实体 ID。
5. 参考资料数量和源字段一致，索引均成功；失败项逐条报告。
6. 目标项目应用的文风与源作品一致。
7. 目标大纲为空，不存在源大纲节点、剧情进度、伏笔或源章节正文。
8. 源作品保持不变。

## 非目标

- 不把本次操作产品化为克隆、导入导出或后台迁移功能。
- 不修改 Core API、Web、CLI、生产 Skill 或数据库结构。
- 不承诺复制运行历史、审核证据、章节溯源或派生索引。
